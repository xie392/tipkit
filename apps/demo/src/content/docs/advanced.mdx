## 进阶

### 扩展机制

扩展集合分两层：`createBasicExtensions()`（段落、标题、加粗、斜体、列表、引用、代码块等基础能力）与 `createAdvancedExtensions()`（表格、KaTeX、分栏、折叠块、目录、附件、图片块、斜杠菜单等高级节点）。两者都可整体省略，也可在返回值上继续追加你自己的 Tiptap 扩展：

```tsx
import { createBasicExtensions } from "@tipkit/extensions";
import { Underline } from "@tiptap/extension-underline";

<TipKitEditor
  deps={deps}
  extensions={[...createBasicExtensions(), Underline]}
/>
```

工具栏逻辑可用 `buildToolbarGroups(editor)` 生成数据，视觉渲染交给你的 UI 层；demo 中另有基于 `@tipkit/ui` 的现成工具栏（`BlockStyleMenu / FontFamilyPicker / FontSizePicker` 等），可直接参考 `apps/demo/src/components/editor-toolbar.tsx`。

### SSR 与 hydration

- 编辑器组件全部为 client 组件，且默认 `immediatelyRender: false`；
- Next.js App Router 中直接使用即可，无需额外配置；
- 若在服务端渲染中需要初始内容，通过 `content` 传入 HTML 字符串即可。

### 常用命令

```bash
pnpm install                      # 安装依赖
pnpm dev                          # 启动 demo
pnpm --filter @tipkit/demo dev    # 只启动 demo
pnpm type-check                   # 全仓类型检查
pnpm test                         # 全仓测试
pnpm build                        # 全仓构建
```
