## Installation

pnpm is recommended (monorepo friendly), but npm / yarn work too:

```bash
pnpm add @tipkit/editor @tipkit/extensions @tipkit/ui @tipkit/components @tipkit/themes
```

`@tipkit/editor` is the aggregate entry point; the other packages (extensions / ui / components / themes) can be imported on demand. To try things out quickly, you can also clone the repo and explore the full example in `apps/demo`.
