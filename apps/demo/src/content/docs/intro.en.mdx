## Introduction

TipKit is a headless rich-text editor suite built on Tiptap v3. "Headless" means logic and visuals are fully decoupled: the core packages handle state and commands, while all styling comes from theme packages (CSS). Swap the CSS and the same editor code becomes a completely different style.

- Stack: Tiptap v3 + React 19 + TypeScript strict
- Single entry point: one `@tipkit/editor` component is all you need
- Built-in themes: default (shadcn standard) and sketch (hand-drawn)
- Self-contained extensions: drop whole directories to trim, import on demand
