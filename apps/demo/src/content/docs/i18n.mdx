## 多语言（i18n）

TipKit 内置轻量 i18n：默认中文，开箱即用；接入方通过 `EditorDeps.t` 注入翻译函数即可切换语言、覆盖文案或新增语言。编辑器内所有用户可见文案（工具栏、斜杠菜单、浮层、KaTeX、表格控制、代码块、附件、提示框等）均走 `t()`，无硬编码。

### 设计概览

- **零依赖**：不引入 i18next / react-intl，仅一个 `createT(messages)` 工具 + `Record<string, string>` 词典。
- **依赖注入**：翻译函数通过 `EditorDeps.t` 注入，编辑器内扩展通过 `useT()` 读取，**不**直接读全局变量。
- **默认兜底**：未注入 `t` 时返回内置中文词典（`zh`），保证开箱即用不报错。
- **类型安全**：`Messages = Record<string, string>`，可用 `Partial<Messages>` 描述部分覆盖。

### 默认行为（不配置）

不传 `t` 时，编辑器使用内置中文：

```tsx
import { TipKitEditor } from "@tipkit/editor";

<TipKitEditor deps={{ uploadImage }} />
```

### 切换内置语言（中文 / English）

`@tipkit/core` 导出 `zh` 与 `en` 两套词典，用 `createT` 包装成 `Translate` 函数注入：

```tsx
import { useMemo, useState } from "react";
import { TipKitEditor } from "@tipkit/editor";
import type { EditorDeps } from "@tipkit/editor";
import { createT, en, zh, type Translate } from "@tipkit/core";

function App() {
  const [lang, setLang] = useState<"zh" | "en">("zh");
  const t = useMemo<Translate>(
    () => createT(lang === "en" ? en : zh),
    [lang],
  );
  const deps = useMemo<EditorDeps>(() => ({ t }), [t]);

  return (
    <>
      <button onClick={() => setLang("zh")}>中文</button>
      <button onClick={() => setLang("en")}>English</button>
      <TipKitEditor deps={deps} />
    </>
  );
}
```

切换 `lang` 后，`deps.t` 引用变化 → `EditorProvider` 重新合并 deps → 所有 `useT()` 消费者（斜杠菜单、浮层、NodeView 等）自动重渲染，编辑器实例与内容保持不变。

### 覆盖部分文案

用对象展开合并内置词典，只改需要的 key：

```tsx
import { createT, zh } from "@tipkit/core";

const myZh = {
  ...zh,
  "toolbar.undo": "撤销操作",
  "slash.searchPlaceholder": "搜索内容…",
};

const deps = { t: createT(myZh) };
```

### 新增语言

以内置 `zh` 为基准补齐缺失 key，避免遗漏：

```tsx
import { createT, zh, type Messages } from "@tipkit/core";

const ja: Messages = {
  ...zh, // 兜底：未翻译的 key 回退到中文（可改为英文 en）
  "toolbar.undo": "元に戻す",
  "toolbar.redo": "やり直し",
  "toolbar.bold": "太字",
  // … 其余 key 按需翻译
};

const deps = { t: createT(ja) };
```

> **提示**：缺 key 时 `t()` 原样返回 key 本身（如 `t("toolbar.image")` 缺失时返回 `"toolbar.image"`），不会抛错。建议上线前对照 `packages/core/src/i18n/zh.ts` 补齐。

### 工具栏接入

`buildToolbarGroups(editor, t)` 接受可选 `t`，传入后工具栏分组数据中的 label / prompt 全部本地化。在 EditorProvider 内部调用时可直接用 `useT()`：

```tsx
import { useT } from "@tipkit/core";
import { TipKitEditor, buildToolbarGroups } from "@tipkit/editor";

<TipKitEditor deps={deps}>
  {(editor) => {
    // children 在 EditorProvider 内，可直接用 hook
    return <ToolbarInner groups={buildToolbarGroups(editor, useT())} />;
  }}
</TipKitEditor>
```

若工具栏渲染在 EditorProvider 外部（如页面级 sticky 工具条），需要自行从外部维护 `lang` 并把 `t` 传给 `buildToolbarGroups`，demo 中的 `apps/demo/src/components/editor-toolbar.tsx` 即此模式（通过 `useDemoLang()` 监听语言切换）。

### 扩展内部使用 useT()

自定义扩展的 React NodeView 内可直接调用 `useT()`（前提是组件树位于 `EditorProvider` 内，`EditorContent` 默认满足）：

```tsx
import { useT } from "@tipkit/core";

function MyNodeView() {
  const t = useT();
  return <button>{t("myExtension.action")}</button>;
}
```

### API 参考

| 导出 | 来源 | 说明 |
| --- | --- | --- |
| `createT(messages)` | `@tipkit/core` | 由词典构造 `Translate` 函数，缺 key 时返回 key 本身 |
| `zh` | `@tipkit/core` | 内置中文词典（默认） |
| `en` | `@tipkit/core` | 内置英文词典 |
| `type Messages` | `@tipkit/core` | `Record<string, string>`，词典类型 |
| `type Translate` | `@tipkit/core` | `(key: string) => string`，翻译函数类型 |
| `EditorDeps.t?` | `@tipkit/editor` | 注入翻译函数；不传走默认中文 |
| `useT()` | `@tipkit/core` | 读取当前 `t`（React hook，需在 Provider 内） |

### 词典 key 命名约定

key 按模块分段，点号分隔，便于查找与覆盖：

- `toolbar.*` —— 顶部工具栏（撤销/重做/加粗/列表/对齐…）
- `slash.*` —— 斜杠菜单（命令 label/description/previewTitle、分组标题、搜索占位）
- `link.*` / `text.*` / `block.*` / `blockHandle.*` —— 浮层与块手柄菜单
- `image.*` / `imagePreview.*` —— 图片块操作与图片预览
- `iframe.*` / `iframeView.*` —— 嵌入网页
- `katex.*` —— 数学公式
- `attachment.*` / `attachmentView.*` —— 附件
- `columns.*` / `details.*` / `callout.*` / `codeBlock.*` / `toc.*` / `table.*` —— 各高级节点
- `placeholder.default` —— 编辑器默认占位符

完整 key 列表见仓库内 `packages/core/src/i18n/zh.ts`（内置中文词典，作为 key 名义的 source of truth）。

### 在线演示

demo 站点（`/docs` → 在线演示）右上角导航栏内置语言切换按钮（与主题切换并列）。点击可在 中文 / English 之间切换，立即生效：

- 斜杠菜单命令名 / 分组标题 / 搜索占位符
- 顶部工具栏按钮 tooltip 与 aria-label
- 文字浮层、块手柄菜单、链接对话框
- KaTeX 编辑器、表格控制、代码块、附件、提示框
- 编辑器占位符

选择会持久化到 `localStorage`，刷新后保持。实现参考 `apps/demo/src/components/site-lang-switch.tsx` 与 `apps/demo/src/components/use-demo-lang.ts`。
