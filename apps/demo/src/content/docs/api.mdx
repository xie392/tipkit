## API 参考

### TipKitEditor Props

| Prop | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `deps` | `EditorDeps` | 是 | 项目特定能力注入（上传 / KaTeX 等） |
| `extensions` | `Extension[]` | 否 | 追加扩展；默认使用基础扩展集合 |
| `content` | `string \| Record<string, unknown>` | 否 | 初始内容（HTML 或 JSON） |
| `contentType` | `"html" \| "markdown" \| "json"` | 否 | 初始内容格式；`"markdown"` 时 content 传 md 字符串 |
| `placeholder` | `string` | 否 | 空状态占位文案 |
| `editable` | `boolean` | 否 | 只读渲染（文档/预览场景） |
| `onChange` | `(editor: Editor) => void` | 否 | 内容更新回调（可通过 getHTML / getJSON 取序列化结果） |
| `onCreate` | `(editor: Editor) => void` | 否 | 编辑器就绪回调，可在此拿到实例 |
| `immediatelyRender` | `boolean` | 否 | SSR 场景传 false（默认 false），避免 hydration 不匹配 |
| `className` | `string` | 否 | 容器类名 |
| `children` | `ReactNode \| (editor) => ReactNode` | 否 | 渲染插槽；传函数可在编辑器就绪后挂载浮层 / 工具栏 |

### EditorDeps

| 字段 | 签名 | 说明 |
| --- | --- | --- |
| `uploadImage` | `(file, editor) => Promise<string>` | 图片上传，返回 `img src` URL |
| `uploadAttachment` | `(file, editor) => Promise<AttachmentMeta>` | 附件上传，返回元数据（url / name / size / mimeType） |
| `renderKatex` | `(tex, displayMode) => Promise<string>` | 数学公式渲染，返回 HTML；服务端 / 客户端均可 |
| `ai` | `AIProvider` | AI 流式文本生成 provider（`AiGeneration` 命令与 `AiMenu` 浮层共用） |
| `t` | `Translate` | i18n 翻译函数，缺省中文词典（详见「多语言」页面） |
| `onCommentCreate` | `(range: CommentRange) => void` | 划词评论创建回调（配合 `Comment` 扩展） |
| `onCommentClick` | `(commentId: string) => void` | 评论标记点击回调 |
